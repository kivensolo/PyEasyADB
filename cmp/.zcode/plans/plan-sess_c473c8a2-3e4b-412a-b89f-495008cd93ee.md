# 新增「应用管理」Tab 页面（UI 参照 H5 设计稿，数据链路沿用现有加载逻辑）

## 方案概要
- H5 参照稿（`cmp/doc/ui-reference/index.html`）**已包含完整的「应用管理」页设计**（`pane-apps` 区块，L1294-1313 + CSS L431-470 + 演示 JS L2101-2199），本次按此设计新开发页面
- 「文件传输」Tab 与其 APK提取 卡片、PullApkDialog 弹窗**全部保持原样不动**（后续做文件传输功能时再移除）
- 内容 Tab 由 5 个变 6 个：快捷操作 | 常用命令 | 按键模拟 | 文件传输 | **应用管理** | 实时预览（应用管理插在文件传输与实时预览之间，实时预览保持末位）
- 数据获取与加载逻辑沿用 PyQt 版同源链路：`AppListLoader.loadAppList`（`adb shell pm list packages -f`，包名/APK路径/类型三字段，第三方优先排序），宿主 Main.kt 持有状态，协程加载，与现有弹窗的状态完全独立

## H5 设计稿要点（实现还原目标）
- **工具栏卡**：搜索框（左置放大镜图标，placeholder「搜索应用名称或包名」，宽 420 上限）+ seg 分段筛选（全部|第三方|系统应用）+ 右侧「共 N 个应用」计数（mono 字体）+ ghost 风格「刷新」按钮
- **应用行卡**（38dp 高，圆角 10dp，flex 列）：序号(mono 10.5sp) → 22dp 彩色圆角图标块(首字母) → 应用名(13sp semibold, 110dp, 省略) → 包名(mono 11sp, flex 1) → APK路径(mono 11sp, flex 1.15, tooltip) → 悬浮浮现的操作区
- **操作区**：第三方应用 = 「提取」mini 按钮；系统应用 = 「系统内置」浅蓝标签（无按钮，对齐 H5；系统 APK 提取仍可走文件传输 Tab 弹窗）
- **空态**：「没有匹配的应用 — 试试其他关键词或分类」；**行入场** rise 动画（500ms ease，行距 45ms 封顶 400ms，复用 Tab 切换 rise 已定稿参数）

## 数据字段适配（现有数据只有 包名/路径/类型）
- 应用名 = 包名最后一段（如 `com.tencent.mm` → `mm`），tooltip 显全包名
- 图标块底色 = 包名哈希映射到固定色板，内容为首字母大写
- 无版本列（`pm list packages -f` 不含版本；后续可用 `--show-versioncode` 扩展，记入 SP 文档「后续演进」）

## 变更清单

### 1. 新建 `cmp/ui/functions/src/main/kotlin/com/easyadb/ui/functions/AppManagerPanel.kt`
与其他 Tab 面板同模块同模式（纯 UI、状态上提宿主）；复用既有积木：seg 控件照 CommandsPanel 的 H5 对齐实现（SegTrack/SegActiveBg/SegActiveText + hover 渐变），卡片照 CmdRow（Surface + shapeLg + hover 描边提亮 PrimaryLight），滚动条照 PullApkDialog（VerticalScrollbar + 共享 listState）。
- 参数：`apps: List<AppListLoader.AppInfo>`、`isLoading`、`selectedDeviceIp`、`onLoadApps: () -> Unit`、`onExtractApk: (AppInfo) -> Unit`
- `LaunchedEffect(selectedDeviceIp)`：进入 Tab 或设备变化自动加载（对齐弹窗「打开即加载」）；刷新按钮同触发
- 状态分支：加载中 / 未选设备（提示去左侧选择）/ 空列表 / 无匹配结果
- 搜索 = 名称+包名小写子串匹配（H5 同逻辑）

### 2. `MainWindowScreen.kt`（ui/home）
- `TAB_MIRROR` 4→5，新增 `TAB_APPS = 4`；`CONTENT_TAB_TITLES` 插入「应用管理」；「五 Tab」相关注释更新为六 Tab
- 新增参数 `apps` / `isAppsLoading` / `onLoadApps` / `onExtractApk`（KDoc 同步）
- `when(tab)` 加 `TAB_APPS -> AppManagerPanel(...)` 分支

### 3. `Main.kt`（desktop-app）
- 新增独立状态：`appList: List<AppInfo>`、`isAppListLoading`（不动弹窗的 pullableApps）
- 抽 `loadApps()` lambda：调 `AppListLoader.loadAppList(selectedDeviceIp)`，回填状态 + 控制台 `[应用列表] 加载 N 个应用`；未选设备报错
- `onExtractApk` 回调：AWT FileDialog SAVE（默认文件名 `包名.→_.apk`）→ `adb -s ip pull` → 控制台回显成功/失败（沿用现弹窗 onPull 实现）
- 在 MainWindowScreen 调用处接线四个新参数
