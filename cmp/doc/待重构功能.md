## 重新对接方式

1. 在 `cmp/desktop-app/src/main/resources/config/menus_ui.xml`（及仓库根 `res/config/` 种子）对应菜单组下加回 `<action>` 节点；
2. 从 `Main.kt` 顶层 `REMOVED_MENU_ACTIONS` 集合中删除对应 action 名；
3. 在 `Main.kt::handleAction` 的 `when` 中恢复分支与对话框 state（参考 git 历史）。

> 注意：menus_ui.xml 为 Python 版与 CMP 版共用种子，本次精简只在 CMP 加载后过滤（`REMOVED_MENU_ACTIONS`），XML 原样保留，Python 版不受影响。
