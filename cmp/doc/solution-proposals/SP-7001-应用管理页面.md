## 1. 背景与目标

设备已装应用此前只有「文件传输 Tab → APK提取 大卡 → PullApkDialog 弹窗」一条入口（弹窗内搜索/筛选/提取）。需要把应用管理升级为内容区一级页面：

- H5 参照稿已包含完整的「应用管理」页设计（pane-apps：工具条 + 行卡列表），本次按稿实现；
- **文件传输 Tab 与其 APK提取 卡片、PullApkDialog 弹窗本轮保持原样不动**（后续做文件传输功能时再移除，见 §6 预留）；
- 数据获取与加载逻辑沿用 PyQt 版同源链路（`adb shell pm list packages -f` → 包名/APK路径/类型，第三方优先排序），不新增 adb 命令。

## 2. Tab 编排

内容区由 5 Tab 变 6 Tab：

```
快捷操作 | 常用命令 | 按键模拟 | 文件传输 | 应用管理 | 实时预览
                                              ↑ 新增（TAB_APPS=4，TAB_MIRROR 顺移 5）
```

- 应用管理插在文件传输与实时预览之间（实时预览保持末位——它带有 SP-4001 窗口级键盘接管等运行态特殊性）；
- H5 稿原始顺序为「…实时预览 | 应用管理 | 文件传输」，CMP 现网序（文件传输在前、实时预览末位）为 P12 既定编排，本次保持现网相对位置仅插入新 Tab。

## 4. 数据字段适配（与 H5 演示数据的差异）

`pm list packages -f` 仅含 包名/APK路径/类型 三字段，H5 演示数据中的 名称/版本/大小/品牌色 无数据来源，按下述口径适配（差异均为有意决策）：

| H5 字段 | 适配 |
|---------|------|
| 应用名 | 取包名尾段（`com.tencent.mm` → `mm`）——无应用名数据，后续可用 `dumpsys package` 拉取 |
| 图标块底色 | 包名哈希映射 10 色色板（跨刷新稳定），非真实应用图标 |
| 版本列 | **不渲染**（数据无版本；后续可用 `pm list packages -f --show-versioncode` 扩展 versionCode） |
| 大小 | H5 行内本就未渲染，无需处理 |
| 操作 | H5 有 提取/打开/清理/卸载 四操作，本轮按用户决策**仅做提取**（所有应用含系统应用均可提取，系统应用附「系统内置」标签；系统 APK 与第三方走同一 adb pull 链路） |
| 提取落点 | H5 直提 Downloads；桌面版沿用 FileDialog SAVE（默认文件名 `包名.→_.apk`）+ 控制台回显——与现网 PullApkDialog 行为一致 |

「第三方」筛选口径沿用弹窗语义：`type != "系统"`（含极少数路径无法归类的「未知」应用）。

## 5. 状态与数据流

沿用「状态上提 + 参数下行/回调上行」约定，与弹窗状态**互相独立**（弹窗保留期间两路并存）：

```
Main.kt（宿主）                          AppManagerPanel（纯 UI）
├ appList: List<AppInfo>                ├ LaunchedEffect(selectedDeviceIp)
├ isAppListLoading                        │   进入 Tab / 设备切换 → onLoadApps()
├ loadApps(): 清旧列表 → 协程调           ├ 搜索/筛选/计数（面板内部 remember 态）
│   AppListLoader.loadAppList → 回填      ├ 行卡 rise 动画 / 空态分支
└ onExtractApk(app): FileDialog          └ 「提取」按钮 → onExtractApk(app)
    SAVE → adb -s ip pull → 控制台回显
```

- 进入 Tab 或设备切换自动加载（AnimatedContent 切走销毁面板、切回重载，对齐弹窗「打开即加载」）；
- 加载前清空旧列表，避免设备切换时闪现上一台设备的数据（清空 + rise 重播为有意观感）；
- 搜索框接入 TextInputFocusTracker（SP-4001 键盘透传的文本框聚焦守卫）；
- 搜索/筛选词不跨 Tab 保留（面板销毁重建，与弹窗行为一致）。

## 8. 变更记录

- **2026-10-16 系统标识图标化（H5 稿更新跟进）**：H5 参照稿将系统行文字标签改为 `.sys-badge` 盾牌+对勾图标徽标并带 title 提示，CMP 同步——AppIcons 新增 `ShieldCheck`（Material `VerifiedUser`），徽标 28×23dp/圆角 7dp/AccentSky tint 底，悬停 ≥300ms 弹出「系统内置 · 受系统保护，不可卸载」气泡（Box+Popup 自建，向左伸展防溢出窗口右缘）。
- **2026-10-16 系统应用可提取（用户走查追加）**：操作区由「系统行只读标签」改为「系统行 = 标签 + 提取按钮」，系统 APK 与第三方走同一 adb pull 链路（H5 原稿系统行为只读标签，此处为有意偏离）。

- **2026-10-16 用户实机走查调优（6 项）**：
  1. rise 错峰入场改为**入场窗口制**——仅新数据会话（apps 实例变化）落地后「错峰上限 400ms + 入场 500ms」窗口内组合的行播放动画；滚动进入视口、筛选/搜索重排直接呈现不重播（原先 LazyColumn 项重建即重播，滚动时反复闪入）；
  2. 包名与路径列**点击复制完整内容**（单行省略布局下拖选只能拿到可见部分；悬浮提亮 + 手型光标提示可点）；路径列同时吃满剩余宽度，截断大幅减少；
  3. 应用名确认设备侧单条命令不可得（详见 §4），维持包名尾段；
  4. 包名列由 weight(1f) 收窄为固定 220dp；
  5. 包名/路径静态色取 **TextHint 与 TextSecondary 的 50% 插值**（`lerp`，明暗主题自适应——TextHint 常显太淡、TextSecondary 常显偏深的折中），hover 仍提亮到 TextSecondary；
  6. 提取/刷新按钮底色对齐 H5 次级按钮**实底**：设计系统新增 `MiniBtnBg`/`MiniBtnBgHover` token（H5 .mini-btn/.btn-ghost：暗 #16223a→#1a2b49、浅 #eef2f9→#dbe7fb），替代原先的透明/Hover 底（H5 浅色稿未覆盖 .btn-ghost，属参照稿疏漏，CMP 统一用 MiniBtn 族）。
