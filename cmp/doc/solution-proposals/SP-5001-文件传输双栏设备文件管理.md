## 1. 背景与目标

文件传输 Tab 现状为 P12 配置化三大卡（APK提取 / 推送文件 / 拉取文件，TemplateGrid 渲染），能力受限于「手输设备路径 + FileDialog」单文件链路。本轮按 H5 参照稿终稿（对齐 Android Studio Device Explorer 交互）整体重构为双栏文件管理页：

- **双栏树**：左 PC 本地文件树 + 右设备文件树，中间拖拽分割条调整宽度；
- **统一交互**：点击行选中、目录行展开/收起（懒加载一层）、路径栏显示选中节点完整路径；
- **传输收口到工具栏**：行内不放传输按钮；双侧工具栏各配「投递」图标（本侧选中文件 → 对侧当前目录）；
- **弹窗化另存/推送**：另存=自定义弹窗（任意本机目录 + 改名，脱离左侧面板限制）；推送=FileDialog 选本机任意文件；
- **拖放上传**：拖任意文件到设备面板即推送到设备当前选中目录（收编待重构 TODO）；
- **传输队列**：底部卡片，v1 不确定进度动画 + 成功/失败终态（真实百分比留演进）。

范围决策（2026-10-17 用户确认）：进度=动画+终态；旧三大卡彻底移除；拖放纳入 v1；常用目录收藏延后（见 §7）。

## 4. 数据采集与解析

### 4.1 设备侧（DeviceFileLister）

- 命令：`adb -s <ip> shell "ls -la '<dir>'"`——**懒加载一层**（初始只列 `/sdcard`，展开时再列子目录），规避 `ls -laR` 全量倾泻（数千条目秒级卡顿 + shell 单次开销）；
- 路径空格：内层单引号包裹（Windows cmd.exe /c 嵌套引号行为实现时以带空格目录实测并固化注释）；
- 执行链路：`ExecUtils.execCmd`（已显式 UTF-8 读 stdout/stderr、并发读取防 4KB 管道死锁——P7 既有教训），超时 15s；失败返回 emptyList + 日志（AppListLoader 先例）；
- 解析规则：跳过 `total N` / `.` / `..`；前 7 列（权限/链接/主/组/大小/日期/时间）按空白切分，**文件名 = 第 7 列后剩余串**（保留空格）；日期两种格式宽容识别（toybox `yyyy-MM-dd HH:mm` 与老版月日时分）；
- 目录「N 项」计数：子级懒加载后回填，未加载显示 `--`；
- mkdir / rm 命令构建器：`shell mkdir '<dir>'` / `shell rm -f '<file>'`（删除仅文件，目录删除留演进）。

### 4.2 PC 侧（PcFileLister）

- `Files.newDirectoryStream` + `readAttributes`，**每条目独立 try-catch 吞 `AccessDeniedException`**（Windows 受限目录大量抛异常）；
- `DosFileAttributes` 过滤隐藏/系统项；OneDrive reparse point 识别跳过（避免触发按需下载）；
- 时间 `yyyy/MM/dd HH:mm`、大小人性化（B/KB/MB/GB）；全部 `Dispatchers.IO`（网络驱动器/OneDrive 列举可能秒级阻塞，UI 只收结果）；
- 根入口：默认打开 `user.home`；盘符导航（`File.listRoots()`）留演进。

## 5. 状态与数据流

```
Main.kt（宿主）                        FileTransferPanel（Tab 面板）
├ transferCenter = TransferCenter()    ├ pcTreeState / devTreeState（remember）
│   ├ jobs: StateFlow<List<TransferJob>>  │   ├ entriesCache / expanded / selectedPath
│   ├ submit(push/pull): IO scope 执行    │   └ 展开即懒加载一层（loading 态）
│   └ 完成项 1.2s 淡出移除               ├ SplitPane(左 FileTreePane(pc), 右 FileTreePane(dev))
└ onLog(message, level) 控制台回显       └ TransferQueue(transferCenter.jobs)
```

- **TransferCenter 挂宿主**：AnimatedContent 切 Tab 会销毁面板组合（协程随之取消），传输任务生命周期必须独立于面板——与 consoleLogFlow 同层级，切 Tab 传输不中断；
- 设备树 `LaunchedEffect(deviceIp)`：进入 Tab / 换设备自动重载根（AppManagerPanel 先例；面板销毁重建即重载，缓存不跨 Tab 保留）；
- 投递守卫：未选中文件 → toast/日志提示「请先选中文件」；目标目录 = 对侧选中目录（选中文件→其父目录；未选中→该侧根：设备 `/sdcard`、PC `user.home`）；
- 命令回显沿用宿主格式：`> adb -s ip push "..." "..."`（level 2）+ 成功/失败方括号消息（level 2/4）。
