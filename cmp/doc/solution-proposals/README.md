# 方案总览（索引）

> 本目录归档 EasyPyADB CMP 端的**功能实现方案文档**。使用方式：**先确定功能，再查下表找到对应编号的方案文档**。
>
> 与其他文档目录的关系：`cmp/doc/` 根下存放专题方案总纲（如 Scrcpy 嵌入模式与焦点控制方案）、`doc/`（仓库根）存放迁移进度与阶段计划；本目录只收**面向实现的落地方案**（做什么、怎么做、怎么验证）。

## 编号规则

方案文档命名：`SP-<功能领域码2位><领域内序号2位>-<中文主题>.md`。

**SP = Solution Proposal（实施方案）**，即「面向实现的落地方案」的文档前缀标识。编号共 4 位数字：

- **前 2 位 = 功能领域码**：标识方案所属的功能领域，由本表统一分配，新领域按需追加；
- **后 2 位 = 领域内序号**：该领域下的第几个方案，从 `01` 起递增，**永不复用**。

示例：`SP-4001` = 镜像预览（40）领域的第 01 号方案。

### 操作约定

- **新增方案**：确定功能领域 → 取该领域现有最大序号 +1 → 按 `SP-XXXX-<中文主题>.md` 命名创建文档 → 在下方索引表登记一行。
- **方案废弃**：不删除文件，状态改为「已废弃」，文档开头注明废弃原因与替代方案编号；序号不复用。
- **方案重大变更**：直接更新对应文档并在文末追加变更记录（日期 + 变更点）。
