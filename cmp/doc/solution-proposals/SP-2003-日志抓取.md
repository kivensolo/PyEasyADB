## 背景与决策

快捷操作 Tab 缺少「把设备日志导出保存到电脑」的能力。H5 参照稿已定稿
三态弹窗交互（配置 → 抓取中 → 完成），本方案将其落地为 Compose 实现。

关键决策（与用户逐项确认过的 H5 定稿对齐）：

1. **抓取中态只展示 loading 动画与真实文件大小，不做实时日志预览**——预览窗口
   对抓取导出场景意义有限，且与 logcat 实时 Tab 功能重叠。
2. **文件大小展示 `File.length()` 每秒轮询的真实落盘体积**，非估算值。
3. **抓取中唯一按钮「停止抓取」，无「取消并丢弃」路径**——避免误点导致长时抓取
   白做；×/Esc/停止三条退出路径一律路由到停止保存。
4. **不做「前置准备命令列表」**（H5 早期稿曾设计可折叠 adb shell 命令区，定稿时
   删除），只保留单一「抓取前清理设备日志缓存」勾选项（先执行 `adb logcat -c`）。
5. **logcat 格式默认 `-v threadtime`**（信息最全，研发分析首选），其余 `-v time` /
   `-v long` / 自定义参数可选。
6. **文件名默认「前缀_日期」模式**（时间戳 `yyyyMMdd_HHmmss`），可 seg 切换整名
   自定义，`.log` 后缀自动补全。

## 链路

```
快捷操作「日志抓取」tile（m_log_capture，accent=violet，XML 第 4 排文本输入之后）
  → Main.kt onFunctionItemClick 拦截 → showLogCaptureDialog = true
  → LogCaptureDialog（ModelessDialogWindow 状态机，独立窗口形态，640dp 配置页，
     配置页高度自动适配内容）
  → 配置页：
      保存目录   输入框 + 浏览（NativeFilePicker：IFileDialog COM 原生文件夹选择，
                 见 2026-10-31 调整2）
      文件名     seg 切换「前缀+日期 / 自定义文件名」；前缀模式下日期只读展示当下
                 时间戳，每次打开弹窗重新取值
      格式单选   -v threadtime（默认）/ -v time / -v long / 自定义参数（展开等宽输入框，
                 空输入回退 threadtime）
      清空勾选   「抓取前清空设备日志缓存」先 adb logcat -c（execAdbCmd 20s 超时，
                 成功后才起抓取进程）；命令预览不展示清理行
      命令预览   tag + mono 命令行实时预览（CmdPreviewText 主题色）
      空目录校验 FieldShakeState 红边抖动 + 控制台提示，不进入抓取链路
  → 抓取中页（420×300 小窗）：
      双环旋转动画（外环 1.1s 顺时针双色弧 / 内环 0.8s 逆时针，中心文档图标 chip）
      + File.length() 每秒轮询真实字节数（tabular-nums）+ 已抓取时长
      + 唯一「停止抓取」危险红渐变按钮；onCloseRequest 同样路由到停止（保存语义）
  → LogcatCapture（core/adb，进程生命周期包装）：
      ProcessBuilder 裸 adb（依赖 PATH，与 captureScreenBytes 一致）参数数组直启
      `adb -s <ip> logcat <opts>`，不经 cmd.exe /c（SP-2001 决策：规避 CRLF/编码污染）
      .redirectOutput(Redirect.to(file))——JVM 以 CREATE+TRUNCATE 打开，重新抓取
      天然覆盖旧文件；stdout 直写文件无需读线程；stderr 守护线程排空（防 4KB 管道
      死锁）并保留末 20 行供诊断
      stop() = destroy + 1s 看门狗 destroyForcibly（仿 ScrcpyLauncher.stop）
      状态机 CaptureState: Idle / Running(file, startedAtMs) / Stopped(exitCode, stderrTail)
      / Failed(message, stderrTail)，StateFlow 推送
  → 停止后成败判定（UI 侧）：Windows destroy() = TerminateProcess(1)，退出码无法
      区分手动停止与异常退出，故按 file.exists() && length > 0 判定——非空文件进
      完成页；空文件带 stderr 尾部回控制台报错并退回配置页
  → 完成页（520×320）：绿勾徽标（spring 回弹缩放）+ 文件路径 + 大小/时长 chip
      + 重新抓取（回配置页）| 打开所在目录（ProcessBuilder explorer.exe，点击后关弹窗）
      | 关闭
```

## 配置持久化

上次使用的保存目录/前缀写 `AppConfig.ini` `[LogCapture]` 段（`AppConfigManager.set +
save()`，与 Theme 写回同模式），下次打开弹窗回填。默认目录取用户 Documents
（fallback user.home）。

## 与 LogcatStream 的关系

`LogcatStream` 面向实时日志面板（逐行解析 LogcatEntry、环形缓冲、DROP_OLDEST），
不适合文件抓取，不复用。`LogcatCapture` 为独立进程生命周期包装，不解析内容。

## 2026-10-31 走查调整（用户逐项确认）

1. **配置页高度自适应**：窗口高度 `Dp.Unspecified`（官方自动尺寸语义），去掉
   内部滚动。坑：自动尺寸下外层 `Surface` 若 `fillMaxSize()` 会把可用高度
   （整屏）全部吃掉，窗口被撑到屏幕高——Config 态必须 `fillMaxWidth()`，仅
   定高态（抓取中/完成）用 `fillMaxSize()`。
2. **选目录改系统原生对话框**：废弃 Swing `JFileChooser`，新建
   `platform/NativeFilePicker`（expect/actual）：Windows 走 IFileDialog COM
   组件（JNA 手写 vtable）+ `FOS_PICKFOLDERS`，与 AWT FileDialog（JDK9+ 同源
   映射 IFileDialog）视觉一致——**文件读取/存储/选目录统一为系统自带样式**。
   COM 异常回退 JFileChooser 兜底。
3. **表单标题高对比**：保存目录/文件名前缀/日期等 FieldLabel 由次级灰改
   `TextPrimary`（用户反馈太不显眼）。
4. **非模态化**：抓取中允许操作主窗口其他功能。坑：`DialogWindow` 模态硬编码
   `DOCUMENT_MODAL` 不可关；低级重载自建 MODELESS ComposeDialog 实测不可行
   （pack/setSize 与渲染层竞态 → 0 高度白窗贴屏幕顶）。最终方案
   `ui/dialogs/ModelessDialogWindow`：包装官方 `Window`（天然 MODELESS）。
   居中坑（三个，均已解决）：
   - `WindowPosition(Alignment.Center)` 相对**屏幕**非主窗口；手动算坐标包
     `.dp` 在 Windows DPI 缩放下 dp/px 混算必漂移——勿手动算，用官方
     Alignment 路径（内部全程 AWT 像素、size 先于 position 应用）；
   - 自动高度首帧未定时提前定位会拿到错误尺寸——`snapshotFlow` 等
     `state.size` 落地（componentResized 回写）再居中；
   - `rememberWindowState` 不传 position 默认 `PlatformDefault`（层叠位置 =
     主窗口左上角+48,48），窗口先可见后修正会闪动——初始 position 直接给
     `Alignment.Center`，首帧 update 内 size/pposition 都在 `isVisible=true`
     之前应用，直接以正确位置出现。
5. **全局等宽字体换 Consolas**：`FontFamily.Monospace` 在 Windows 落到
   Courier New（笔画细 + 灰度抗锯齿，小字号发虚）。新建 token
   `easyAdbMonospace`（Typography.kt）：从 `%WINDIR%\Fonts/consola.ttf /
   consolab.ttf` 加载，缺失回退 Monospace；全 UI 18 处引用统一替换。
6. **清理勾选简化**：去卡片包裹与副文案，改「勾选框 + 单行文字」；文案改
   「抓取前清空设备日志缓存」；命令预览区不再展示清理行（清空动作仍实际
   执行，仅不预览）。
7. **命令预览文字色改主题 token**：原硬编码暗色 `#bcd7fb`，亮色下发浅。新增
   `CmdPreviewText`（亮 `#1d4ed8` / 暗 `#bcd7fb`，对齐 H5
   `html[data-theme=light] .cmd-preview .cmd`）。
