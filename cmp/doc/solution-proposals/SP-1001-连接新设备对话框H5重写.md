## 背景与决策

设备列表区头部「新建设备连接」入口（`AddDevicePillButton` → `onAddDevice`）唤起的
`NewConnectDialog` 是早期占位实现：Material `OutlinedTextField` + 单个 IP 输入行 +
行内连接按钮（400×170 DialogWindow），样式与 H5 参照稿脱节，且**没有设备名称入口**——
设备库 `DeviceRecord.alias` 无从写入，设备卡只能显示裸 IP。

H5 参照稿 `#modalDevice`（index.html:1643-1662）是「遮罩 + 居中卡片」的**页内 modal**：
设备名称 / IP 地址 / 端口三字段 + 头部标题/关闭钮 + 底部「取消/连接」。本次按 H5 规格
重写，并打通「名称 → 设备库 alias」链路，连接成功后设备卡直接显示用户命名。

**关键决策一——窗口形态：主窗口内浮层，非独立 OS 窗口。** 首版实现沿用工程惯例做成
`DialogWindow`（原生标题栏 + 窗口图标），走查暴露两个不可调和的问题：
1. 原生标题栏与 Android logo 在 H5 设计稿中不存在（走查反馈）；
2. H5 modal 的核心视觉是**暗色遮罩浮层**（.modal-backdrop rgba(4,7,13,.62) + blur），
   独立 OS 窗口物理上做不出「盖在主界面上的遮罩」。

且独立窗口还需 `undecorated` + DWM 圆角（SP-9002）+ 手动估高（首版就因 DialogWindow
size 含标题栏、内容估高不足把按钮行整行裁掉）。改为**主窗口满窗 Box 内的最后一层浮层**
一次性解决全部问题：遮罩/居中/圆角/高度全由 Compose 布局决定，无窗口句柄、无 DWM、
无固定高度。

**关键决策二——设备名称可选（与 H5 必填不同）**：H5 侧名称必填（校验 toast「请填写设备
名称和 IP 地址」）；Compose 端存在**重连已有设备**场景（设备 IP 已在库中、别名已存在），
强制填名会迫使每次重连都改名或重复输入旧名。故名称不参与校验：非空 → 覆盖 alias，
留空 → 保留库中旧别名。新设备首次连接留空则 alias 为空串，设备卡回落显示 IP（既有
DeviceListPanel 逻辑）。

## 链路

```
设备列表「+ 新建设备连接」(Main.kt showNewConnectDialog)
  → 主窗口满窗 Box 最后一层渲染 NewConnectDialog 浮层
      遮罩   ModalScrim 全窗，点击 = 关闭（卡片自身拦截点击防穿透关闭）
      卡片   居中 440dp 宽、高度随内容：ModalBg 渐变 + 1px Border + 18dp 圆角
      头部   标题「连接新设备」16sp/700 + 30dp 关闭钮（hover 亮底）
      三字段 设备名称（可选，placeholder「例如：书房电视」）
             IP 地址（必填，NetworkUtils.isIpMatches 校验，placeholder 192.168.1.120）
             端口（默认 5555；空按 5555，非数字/越 1..65535 报错）
      校验   失败 → 字段区下方内联红字（11sp StatusUnauthorized），重新输入即清除
  → onConnect(name, "ip:port")（对话框拼好端口，宿主不再补全）
  → Main.kt：adb connect → 成功后入库
      alias = name.ifBlank { existing?.alias.orEmpty() }   // 非空覆盖 / 留空沿用
      connectCount +1、deviceInfo 沿用旧记录（合并逻辑不变）
  → reloadDevices → 设备卡显示命名
```

## H5 规格与 Compose 取舍

| H5 | Compose 实现 | 取舍说明 |
|---|---|---|
| .modal-backdrop 全屏 rgba(4,7,13,.62) + backdrop-filter blur(5px) | 满窗 Box `ModalScrim`（明暗同值）+ `clickable` 关闭 | blur 无对应 API 不复刻（已知边界）；卡片 `clickable(indication=null)` 空实现拦截点击防穿透到遮罩误关 |
| .modal 卡片 440px、18px 圆角、渐变底、1px var(--line-2) 边框 | 居中 Box width(440dp)，`background(垂直渐变, 18dp shape)` + `border`，**高度随内容** | 无固定窗口高度 → 按钮行永不裁切（首版教训）；阴影略（浮层自带遮罩层次感） |
| .modal-head（标题 + .modal-x 30×30/8px 圆角 hover） | Row + 16sp Bold 标题 + ModalCloseButton（Icons.Filled.Close 14dp，hover ModalXHoverBg 底 + 字色转亮） | 与 H5 等效；无原生标题栏/logo |
| .mfield label 12.5px/600 + input 等宽 13px、40dp、10px 圆角、focus 蓝描边 | `MField` 自绘：label Text + Box(40dp) border/background + BasicTextField 13sp Monospace | 参照 AppParamPanel.CompactTextField 模式；规格不同，按 Sonar 3 处阈值不提取 |
| 校验失败 toast | 字段区下方内联红字行（恒占位防跳动） | Compose 端无全局 toast；内联在字段旁语义更准 |
| .modal-foot 右对齐 gap 10、padding 18/22/20 | Row(spacedBy 10dp, End) + DialogPrimaryButton/DialogPlainButton | 按钮规格复制自 ScreenshotDialog（.btn 为 modal 通用样式），private 复制不提取 |
| modal 打开期间背景不可交互 | 遮罩 clickable 吞掉全部指针事件；`DisposableEffect` 向 TextInputFocusTracker 上报聚焦 | 浮层在主窗口内（无独立键盘管线），须防实时预览键盘接管（SP-4001）把输入转投 scrcpy——浮层存续期间键盘本地优先，MField 字段级再叠加一层上报 |

## 已知边界

- 遮罩 blur（backdrop-filter）无对应 API，未复刻；遮罩纯色 62% 黑。
- 浮层无 Esc 关闭（H5 亦无）、不可拖拽移动（H5 modal 固定居中）。
- 浮层遮断主窗口交互（H5 等效行为）；不影响其他 DialogWindow 弹窗的独立键盘管线。
- 焦点不自动落在首个输入框（H5 无 autofocus，保持一致）。
